Неофициальное кооперативное расширение [WKMultiMod автора Shen-X-L](https://github.com/Shen-X-L/WKMultiMod): прямое подключение, цепь между игроками и ручные сохранения общего прохождения.

## Возможности

| Возможность | Подробности |
| :--- | :--- |
| Прямое подключение | IP и TCP порт, включая общую сеть Radmin VPN. Адрес по умолчанию пустой. |
| Совместное лазание | Модели напарников, цепь на уровне корпуса, захваты игроков, свет чужого фонарика и временные метки. |
| Личные вещи | Раздельные инвентари, общие деньги и перки, обмен предметами и закрепление легендарок за владельцем. |
| Ручные сохранения | Хост сохраняет и загружает группу. Просмотр, редактирование и удаление с подтверждением. |
| Общий мир | Синхронизация кнопок, дверей, растений и врагов. Экспериментальный режим карты хоста. |
| Два языка | Независимый выбор русского или английского без переустановки. Возвращён прежний русский шрифт. |

## Установка и подключение

1. Нужны White Knuckle **0.60g** и BepInEx **5**. Версия мода должна совпадать у обоих.
2. Закройте игру. Распакуйте пакет мода рядом с `White Knuckle.exe`, объединив папку `BepInEx`.
3. Хост запускает одиночную игру, открывает меню паузы, выбирает создание комнаты, отмечает параметры и создаёт комнату.
4. Друг открывает **Мультиплеер**, затем **Radmin**, вводит IP хоста и такой же порт. Стандартный TCP порт: **47653**.
5. Для Radmin VPN оба компьютера должны находиться в одной сети VPN.

## Управление

| Клавиша | Действие |
| :--- | :--- |
| F1 | Сохранить игру, только хост |
| F4 | Загрузить последнее подходящее сохранение, только хост |
| Enter | Открыть чат или отправить сообщение |
| Колёсико мыши | Поставить временную общую метку |
| Удержание колёсика и прокрутка | Выбрать расстояние до метки, отпустить для установки |
| G | Переключить режим захвата напарника |
| F8 | Открыть резервную панель подключения |

Клавиши сохранения и загрузки меняются в настройках клавиатуры. Язык каждый игрок выбирает отдельно.

## Сборка

Библиотеки самой игры не распространяются. Укажите путь к своей установленной игре:

```powershell
dotnet build src/Core/WKMultiPlayerMod.csproj -c Release -p:GamePath="C:\Path\To\White Knuckle" -p:DeployToGame=false
```

Поместите две собранные DLL мода и содержимое `resources/` в `BepInEx/plugins/SimpleMultiPlayer/`.

## Проверки и ограничения

Игровые изменения 1.21 прошли четыре полных прогона двумя отдельными локальными процессами Unity, проверки сети, физики цепи, интерфейса и сохранений. Версия 1.21.1 возвращает прежний русский шрифт и убирает готовый адрес подключения. Она успешно собирается, но четыре полных прогона после этих двух изменений не повторялись.

Мод экспериментальный. Проверки на одном компьютере не гарантируют работу любой сети VPN и каждого варианта генерации. Цепь не огибает препятствия. Карта хоста остаётся экспериментальным режимом. Перед обновлением делайте резервную копию сохранений. Финальная комната кампании завершает доступную кампанию, продолжение после неё мод не добавляет.
