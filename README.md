An unofficial cooperative extension of [WKMultiMod by Shen-X-L](https://github.com/Shen-X-L/WKMultiMod), with direct LAN connections, optional tethers and manual multiplayer checkpoints.

**[Download 1.21.1](https://github.com/abobik1231/WhiteKnuckle-Coop/raw/refs/heads/main/dist/WhiteKnuckle-Coop-1.21.1.zip)**

## What you get

| Feature | Details |
| :--- | :--- |
| Direct connection | Join by IP and TCP port, including a shared Radmin VPN network. |
| Cooperative climbing | Visible teammates, optional waist tether, player grabs, shared flashlight light and temporary pings. |
| Personal equipment | Separate inventories, shared currency and perks, transferable items and ownership tracking for legendary artifacts. |
| Manual checkpoints | Host saves and restores the group. Browse, edit and delete saves with confirmation. |
| Shared world | Buttons, doors, plants and enemy synchronization. Optional experimental host map mode. |
| Bilingual interface | English by default, with an optional Russian translation. Language can be changed without reinstalling. |

## Install and connect

1. Use White Knuckle **0.60g** and BepInEx **5**. Both players need the same mod version.
2. Close the game. Extract the release package beside `White Knuckle.exe`, merging `BepInEx`.
3. Host: start a solo run, open the pause menu, choose **Create lobby**, select the options and create the room.
4. Guest: open **Multiplayer**, choose **Radmin**, enter the host address and matching port. Default TCP port: **47653**.
5. With Radmin VPN, both computers must belong to the same VPN network.

## Controls

| Key | Action |
| :--- | :--- |
| F1 | Save the run, host only |
| F4 | Load the latest compatible checkpoint, host only |
| Enter | Open chat or send a message |
| Middle mouse | Place a temporary shared ping |
| Hold middle mouse and scroll | Adjust ping distance, release to place |
| G | Switch teammate grab mode |
| F8 | Open the fallback connection panel |

Save and load keys can be changed in keyboard settings. Each player chooses their interface language independently.

## Build from source

Game assemblies are deliberately excluded. Provide your own game installation:

```powershell
dotnet build src/Core/WKMultiPlayerMod.csproj -c Release -p:GamePath="C:\Path\To\White Knuckle" -p:DeployToGame=false
```

Copy the two generated mod DLLs and the files in `resources/` into `BepInEx/plugins/SimpleMultiPlayer/`.

## Testing and limits

The underlying 1.21 gameplay changes passed four complete paired runs in separate local Unity processes, plus transport, tether physics, UI and checkpoint regression checks.

This is an experimental mod, not official multiplayer. Local tests do not establish reliability on every VPN connection or every generated room. Tethers do not wrap around obstacles. Host map synchronization remains experimental. Back up saves before updating. The final campaign room is the end of the available campaign, not a missing continuation generated by this mod.
